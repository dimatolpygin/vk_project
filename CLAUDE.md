# Деплой бота
- практика ci\cd гитхаб экшен в репо https://github.com/dimatolpygin/vk_project
- при изменениях в коде делать пуш + комиты.

# Старт сессии
1. Прочитать `docs/STATUS.md` — текущий этап, активная работа, блокеры.
2. Сверить с git: `git tag -l "stage-*"` и `git log --oneline -10`. Тег > чекбоксы > проза STATUS.
3. Открыть `docs/ROADMAP.md` на текущем этапе — там открытые acceptance-чекбоксы.
4. Только после этого браться за задачу.
