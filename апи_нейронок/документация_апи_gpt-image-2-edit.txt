Openai Gpt-image-2 Edit
OpenAI's GPT Image 2 Edit enables image editing from natural-language instructions with one or more reference images. Ready-to-use REST inference API, best performance, no coldstarts, affordable pricing.

1. Calling the API
Submit a request
The SDK handles polling automatically and returns the result once the task is complete. If you're using cURL or raw HTTP, see Queue & Webhooks for how to retrieve results.


curl -X POST "https://api.wavespeed.ai/api/v3/openai/gpt-image-2/edit" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $WAVESPEED_API_KEY" \
  -d '{
    "enable_base64_output": false,
    "enable_sync_mode": false,
    "images": [
        "https://static.wavespeed.ai/examples/0672442676064bef9c4a4e2b9fe5139a/1776786640458643012_6ubpCLU4.png"
    ],
    "prompt": "A high-end fashion editorial portrait of a blonde Western female model wearing the earrings shown in...",
    "quality": "medium",
    "resolution": "1k"
}'

2. Authentication

Get your API Key
Get your API key from https://wavespeed.ai/accesskey.

Environment variable
export WAVESPEED_API_KEY="your-api-key"

3. Queue & Webhooks
For long-running requests, you can either poll for results or use webhooks.

Submit request
# Without webhook (poll for results)
curl -X POST "https://api.wavespeed.ai/api/v3/openai/gpt-image-2/edit" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $WAVESPEED_API_KEY" \
  -d '{
    "enable_base64_output": false,
    "enable_sync_mode": false,
    "images": [
        "https://static.wavespeed.ai/examples/0672442676064bef9c4a4e2b9fe5139a/1776786640458643012_6ubpCLU4.png"

  -d '{
    "enable_base64_output": false,
    "enable_sync_mode": false,
    "images": [
        "https://static.wavespeed.ai/examples/0672442676064bef9c4a4e2b9fe5139a/1776786640458643012_6ubpCLU4.png"

Get the result
Polling
# Check status
curl -X GET "https://api.wavespeed.ai/api/v3/predictions/{request_id}" \
  -H "Authorization: Bearer $WAVESPEED_API_KEY"

# Possible statuses: pending → processing → completed | failed
# Poll every 1-2 seconds until status is "completed" or "failed"

# Get result (when status is "completed")
curl -X GET "https://api.wavespeed.ai/api/v3/predictions/{request_id}/result" \
  -H "Authorization: Bearer $WAVESPEED_API_KEY"

Webhook
If you added ?webhook=<your_url> when submitting, WaveSpeed sends a POST to your URL when the task completes:

{
    "id": "<task_id>",
    "model": "openai/gpt-image-2/edit",
    "input": {
        "enable_base64_output": false,
        "enable_sync_mode": false,
        "images": [
                "https://static.wavespeed.ai/examples/0672442676064bef9c4a4e2b9fe5139a/1776786640458643012_6ubpCLU4.png"
        ],
        "prompt": "A high-end fashion editorial portrait of a blonde Western female model wearing the earrings shown in...",
        "quality": "medium",
        "resolution": "1k"
    },
    "outputs": ["<output_url>"],
    "status": "completed",
    "created_at": "<timestamp>",
    "error": null
}

Field	Description
id	Task ID
outputs	Array of output URLs (only when status: "completed")
status	completed or failed
error	Error message (only when status: "failed")
Best practices:
Use HTTPS endpoint
Return 2xx immediately
Implement idempotency
Verify signatures (see below)
📖 For more details, see Get Result | Webhooks.

4. Verifying Webhooks
Always verify webhook signatures to ensure requests are from WaveSpeed.

Webhook headers
Each webhook request includes these headers:

Header	Description
webhook-id	Unique identifier for this webhook delivery
webhook-timestamp	Unix timestamp when the webhook was sent
webhook-signature	Signature in format v3,<hex_signature>
Signature computation
HMAC_SHA256(secret_without_prefix, "{webhook-id}.{webhook-timestamp}.{raw_body}")

⚠️ Important: Remove the whsec_ prefix from your webhook secret before using it as the HMAC key. Do NOT base64 decode it.

5. Files
Many input parameters — such as image, images, mask_image, video, and audio — accept file URLs or Base64 data URIs.

Public URL
Pass publicly accessible URLs directly:


{
    "image": "https://example.com/image.png",
    "images": ["https://example.com/image.png"],
    "mask_image": "https://example.com/mask.png"
}

Base64 data URI
Embed files as Base64:


{
    "image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA...",
    "images": ["data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA..."],
    "mask_image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA..."
}

Upload API
Upload local files to get a URL.

Endpoint:

POST https://api.wavespeed.ai/api/v3/media/upload/binary

Request:

curl -X POST "https://api.wavespeed.ai/api/v3/media/upload/binary" \
  -H "Authorization: Bearer $WAVESPEED_API_KEY" \
  -F "file=@/path/to/image.png"

Response:

{
    "code": 200,
    "message": "success",
    "data": {
      "type": "image",
      "download_url": "https://cdn.wavespeed.ai/uploads/xxx.png",
      "filename": "image.png",
      "size": 1024000
    }
}

💡 For files larger than 300MB, use a URL input instead of uploading directly.

6. Schema
Input
Parameter	Type	Required	Default	Range	Description
images	array	No	--	--	List of URLs of input images for editing.
prompt	string	No	--	--	The positive prompt for the generation.
aspect_ratio	string	No	--	1:1, 3:2, 2:3, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9	The aspect ratio of the generated image. Auto-detected from input image if not specified.
resolution	string	No	1k	1k, 2k, 4k	The resolution of the output image.
quality	string	No	medium	low, medium, high	The quality of the generated image. Higher quality costs more.
enable_sync_mode	boolean	No	--	--	If set to true, the function will wait for the result to be generated and uploaded before returning the response. It allows you to get the result directly in the response. This property is only available through the API.
enable_base64_output	boolean	No	--	--	If enabled, the output will be encoded into a BASE64 string instead of a URL. This property is only available through the API.
