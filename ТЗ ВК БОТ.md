# ТЗ на VK-бота для нейрофотосессий

## 1. Общая задача

Разработать VK-бота для нейрофотосессий.

Требования по ИИ и интеграциям:

- Бот должен работать с моделями `nano-banana-pro` или `nano-banana-2`.
- В качестве агрегатора требуется использовать `WaveSpeed`.

## 2. Логика бота

### 2.1. Вход в бота

- При переходе в бота пользователь получает приветственное сообщение.
- По возможности в приветственном сообщении нужно использовать изображение.

После нажатия кнопки `Старт` появляется сообщение с пояснительным текстом и кнопками:

- `Попробовать бесплатно`
- `Активировать все функции`
- `Примеры работ`
- Дополнительная кнопка / раздел (уточняется)

### 2.2. Бесплатная генерация

При нажатии на `Попробовать бесплатно`:

- Пользователю показывается сообщение с изображением.
- В тексте должен быть призыв подписаться на группу VK, чтобы получить бесплатную генерацию.
- Бот должен проверять наличие подписки.
- Без подписки бесплатная генерация недоступна.

Под сообщением должны быть кнопки:

- `Подписаться на группу`
- `Я подписался`
- `Назад`

После нажатия `Я подписался`:

- Пользователю показывается сообщение с требованиями к фото для бесплатной генерации.
- Также пользователь должен выбрать пол.

После отправки фото:

- Появляется сообщение о необходимости подождать 1-2 минуты.

После получения результата:

- Пользователь получает сообщение-прогрев о том, что внутри бота доступны дополнительные функции, образы и другие возможности.

Под этим сообщением должны быть кнопки:

- `Получить еще бесплатные фото`
- `Активировать все функции`
- `Назад`

При нажатии на `Получить еще бесплатные фото`:

- Пользователь получает реферальную ссылку.
- За каждого приглашенного пользователя рефовод получает `2` бесплатные генерации.

### 2.3. Платный доступ

При нажатии на `Активировать все функции`:

- Пользователю показывается сообщение с тарифами для оплаты.
- Тарифы должны настраиваться через админку.

После оплаты:

- Открывается полное меню со всеми функциями.

### 2.4. Примеры работ

При нажатии на `Примеры работ`:

- Пользователю показывается сообщение с коллажем примеров работ и описанием.

Ниже должны быть кнопки:

- `Активировать все функции`
- `Назад`

## 3. Функции после оплаты

После оплаты пользователю становятся доступны следующие разделы:

- `Фото по готовым промтам`
- `Фото по своему промту`
- `Изменить фото/картинку`
- `Парные и семейные фото`
- `Бесплатные генерации`
- `Запомнить мое фото`

Также должно быть нижнее меню:

- `Главное меню`
- `Купить генерации`
- `Настройки`
- `Техподдержка`

### 3.1. Фото по готовым промтам

В этом разделе:

- При переходе показываются готовые места и события.
- Логика должна быть аналогична боту в Telegram `@photolike_ai_bot`, если перенос возможен.
- Шаблоны должны быть сгруппированы по категориям.
- Пример категорий: `Студия`, `Природа` и т.д.
- При нажатии на категорию открываются все шаблоны этой категории.
- Отображение шаблонов желательно сделать в `2` колонки.
- Количество шаблонов внутри категории не фиксировано.
- Категории задаются администратором через админку.
- Нужна фильтрация на основе ранее выбранного пола.
- Группировка категорий может строиться по общему `id`.

### 3.2. Фото по своему промту

При переходе в раздел:

- Показывается пояснительное сообщение с картинкой.
- Пользователь загружает фото.
- Пользователь добавляет свой промт.
- В ответ получает соответствующую генерацию.

После генерации под изображением должны быть кнопки:

- `Изменить промт` — пользователь задает новый промт для этого же фото
- `Скачать фото`
- `Назад`

### 3.3. Изменить фото/картинку

В этом разделе:

- Показывается сообщение с пояснением, как использовать раздел.
- Пользователь может загрузить готовое изображение.
- Либо может сделать фото в реальном времени и изменить его.
- Обязательно нужна кнопка `Назад`.

### 3.4. Парные и семейные фото

При переходе в раздел:

- Показывается пояснительное сообщение с картинкой.
- Отображаются две кнопки:
  - `Пара`
  - `Семейное фото`

Дополнительная логика:

- Под кнопкой `Пара` доступны промты для парных фото.
- Под кнопкой `Семейное фото` доступны промты для семейных фото.
- Логика работы должна быть аналогична режиму с готовыми промтами.

### 3.5. Бесплатные генерации

В этом разделе должна быть реализована реферальная программа:

- За каждого пользователя, который оплатил любое количество генераций, рефовод получает `2` бесплатные генерации.

### 3.6. Запомнить мое фото

В этом разделе:

- Пользователь отправляет свое фото боту.
- Бот использует это фото как базу для последующих генераций.
- Пользователь должен иметь возможность заменить фото, если исходное оказалось неудачным.

Ограничение:

- Это фото используется только для раздела `Фото по готовым промтам`.

## 4. Нижнее меню

В нижнем меню должны быть кнопки:

- `Главное меню`
- `Купить генерации`
- `Настройки` (`качество`, `формат`, `баланс`)
- `Техподдержка`
- `Примеры работ`

## 5. Админка

Требуется веб-версия админки.

Обязательные требования:

- Абсолютно все сообщения, изображения и кнопки, которые используются в боте, должны быть доступны для редактирования через админку.

Статистика по пользователям:

- Количество пользователей
- Ссылки на страницы VK
- История покупок
- Остаток генераций
- Статистика по рефералам
- Дата регистрации

Дополнительно:

- Нужна статистика по кнопкам и разделам, чтобы видеть, какие сценарии используются чаще всего.

## 6. Технические требования

- Целевой сервер: `2` ядра, `2 GB` RAM
- Планируемая нагрузка: `10 000` пользователей
- Нужна практика `CI/CD` через GitHub Actions
- Git-структура: `dev` для разработки и `main` для продакшена
- Публичный репозиторий: [github.com/dimatolpygin/vk_project](https://github.com/dimatolpygin/vk_project)

### 6.1. Развертывание

Нужен скрипт установки на сервер:

- Пользователь передает ссылку на репозиторий.
- Далее автоматически выполняется:
  - обновление сервера Ubuntu
  - установка зависимостей
  - запуск контейнеров `Redis` и `PostgreSQL`
- Пользователь должен только заполнить `env`.
- Также пользователь должен создать секреты GitHub-репозитория, включая `SSH_KEY`.

Дополнительно:

- Нужен скрипт для автоматической регистрации вебхуков.
- В качестве примера указан файл:
  - `D:\claude\боты_портфолио\set-webhooks.ps1`
- Для автосборки при изменении файлов нужен `air`.
